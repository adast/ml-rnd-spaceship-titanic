# Данные и их происхождение

Оригинал: [Spaceship Titanic, Kaggle](https://www.kaggle.com/competitions/spaceship-titanic/data),
Addison Howard, Ashley Chow, Ryan Holbrook, 2022. На официальной странице указана
лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

`PROVENANCE.json` содержит источники, фиксированные версии, размеры и SHA-256.
В этой среде официальный API загрузки вернул HTTP 401, поэтому использована
публичная копия CSV с Hugging Face. Две независимо размещенные копии `train.csv`
совпали побайтно и с опубликованным SHA-1 Git-объекта. Контрольная сумма
официального файла Kaggle недоступна; совпадение с ним не утверждается.

```bash
python scripts/download_data.py
python scripts/download_data.py --verify-only
```

Получаются `data/raw/train.csv` (8693 размеченные записи) и `test.csv` (4277 записей
без целевой переменной). Загружаются только данные; чужие решения и прогнозы
не использованы. Исходные CSV исключены из Git и включены в локальный архив
для сдачи, чтобы запускать проект без сети.

Окончательная отложенная выборка выделена из размеченного файла целыми группами
до разведочного анализа. Ее метки не участвуют в моделировании и метриках HW1.
Разведочный анализ и разбор ошибок относятся только к рабочей выборке
(development). Точный список идентификаторов и назначений фолдов хранится
в `data/splits/assignments.csv`. После создания он защищен проверкой контрольной
суммы от случайной замены. Это дисциплина работы с данными, а не физическое
скрытие меток: исходный `train.csv` по-прежнему содержит все строки.

Указание авторов и лицензии относится к исходному набору данных, а не к коду
и отчету проекта.
