# План экспериментов ДЗ2

В ДЗ1 логистическая регрессия B1 верно предсказывала исход в среднем для 78,803 % пассажиров на пяти проверочных частях выборки. Добавление палубы и борта каюты повысило долю верных ответов на 0,775 процентного пункта по всем проверочным прогнозам. Даже при высокой уверенности регрессия ошибалась, в частности в прогнозах для пассажира в криосне и пассажира с большими расходами на услуги. [Результаты ДЗ1](CONCLUSIONS.md)

## Гипотезы

1. **Бустинг.** В логистической регрессии логарифм шансов перемещения зависит от расходов линейно. Дерево может использовать разные пороги расходов в зависимости от палубы или криосна. Проверим, повысит ли градиентный бустинг долю верных ответов на тех же признаках.
2. **Номер каюты.** В поле `Cabin` записаны палуба, номер и борт. Предполагаем, что на одном борту одной палубы доли перемещённых пассажиров в соседних по номеру каютах близки. Проверим, добавляет ли номер каюты информацию о перемещении, когда палуба и борт уже известны. В данных нет точных координат кают. Пропущенный номер заменим медианой, рассчитанной по обучающей части. [Поля набора данных](https://www.kaggle.com/competitions/spaceship-titanic/data)

| Вариант | Модель | Учитывает номер каюты |
| --- | --- | --- |
| B1 | Логистическая регрессия из ДЗ1 | Нет |
| C | Логистическая регрессия из ДЗ1 | Да |
| M | Гистограммный градиентный бустинг | Нет |
| MC | Гистограммный градиентный бустинг | Да |

Сравним все варианты с B1. Две абляции покажут вклад каждого изменения. Разность долей верных ответов MC и M покажет, сколько даёт номер каюты в бустинге. Разность между MC и C покажет, сколько даёт замена регрессии бустингом, когда номер известен обеим моделям.

## Обучение и проверка

Сохраним преобразования признаков из ДЗ1, включая кодирование категорий и стандартизацию числовых признаков. При обучении бустинга будем минимизировать логарифмические потери. При каждом обучении построим 150 деревьев с шагом обучения 0,08. В дереве будет не более 15 листьев и не менее 20 обучающих примеров в каждом листе. Коэффициент L2-регуляризации равен 1, начальное значение генератора случайных чисел для модели равно 42. Отключим раннюю остановку, чтобы использовать все четыре части, отведённые для обучения. [Настройки бустинга](../configs/hw2.yaml) · [Описание алгоритма в scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html)

В рабочей выборке 6968 пассажиров из 4986 групп. При каждом разбиении пассажиры одной группы попадают в одну часть выборки. Используем разбиения и порог 0,5 из ДЗ1. Сначала сверим прогнозы B1 с сохранёнными прогнозами ДЗ1. Для выбора модели используем разбиение с начальным значением 42. Выберем вариант с наибольшей средней долей верных ответов по пяти проверочным частям. При равенстве результатов возьмём первый вариант в порядке B1, C, M, MC. Разбиения 17 и 2026 покажут, сохраняется ли преимущество при другом составе групп. Ещё 1725 пассажиров оставим для итоговой проверки. [Правило выбора модели](PREREGISTRATION.md) · [Параметры разбиений](../configs/baseline.yaml)

Для каждого обучения сохраним настройки, прогнозы и метрики. Разности долей верных ответов сравним по фолдам. По всем проверочным прогнозам посчитаем также исправленные и новые ошибки. Для 95%-х интервалов 2000 раз выберем с возвращением целые группы пассажиров, используя начальное значение генератора 9187. В каждом повторе сравним модели на одних и тех же группах. Интервалы характеризуют разброс при фиксированных прогнозах. Влияние повторного обучения и выбора лучшего варианта в них не входит. Качество самих вероятностей оценим по логарифмическим потерям.
