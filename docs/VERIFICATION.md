# Проверка воспроизводимости

Основной запуск: `./scripts/run_baseline.sh`.

Повторный запуск с теми же закрепленными версиями и исходниками:

```bash
python -m venv .venv-repro
.venv-repro/bin/python -m pip install -r requirements.txt
PYTHON_EXECUTABLE=.venv-repro/bin/python \
  ./scripts/run_baseline.sh --output reports/reproduction
PYTHONPATH=src .venv-repro/bin/python -m spaceship_hw1 verify
```

Для проверенной сборки без сети на Linux x86_64 / CPython 3.14 нужен отдельный
`spaceship-hw1-offline-wheels.zip`. Из родительской папки проекта распакуйте его:

```bash
unzip -n spaceship-hw1-offline-wheels.zip
```

Архив содержит `spaceship-hw1/vendor/wheels/`. Перенесите полученный
`vendor/wheels` в корень `ml-rnd-spaceship-titanic`. Затем вместо сетевой установки:

```bash
.venv-repro/bin/python -m pip install --no-index --find-links vendor/wheels \
  --require-hashes -r requirements-linux-py314.lock
```

`verify` проверяет:

1. Совпадение предсказанных и истинных классов, `PassengerId`, `seed`, `fold`
   и `model`.
2. Совпадение OOF-вероятностей с допустимым абсолютным отличием 1e-9.
3. Совпадение SHA-256 данных, конфигурации, описания разбиений и исходников,
   а также версий библиотек.
4. Независимый пересчет метрик каждого фолда по таблице прогнозов
   с допустимым абсолютным отличием 1e-10.

Фактическая проверка записана в `reports/reproduction_check.json`.
В `reports/run_metadata.json` сохранены платформа, версии, время и каждое обучение.
Время и даты запусков могут отличаться. Проверка проводится на одной платформе
с теми же BLAS и версиями библиотек; небольшие численные отличия на других
платформах требуют отдельного исследования.

После рефакторинга контрольные суммы исходников закономерно меняются.
Поэтому совпадение прогнозов с предыдущей версией проверяется отдельно;
обычный `verify` сравнивает два запуска текущих исходников. Результаты проверки
после редакторской и кодовой правки записаны в `reports/VALIDATION.json`.

Для отдельной проверки стиля нужны инструменты разработки:

```bash
python -m pip install pycodestyle==2.15.0 ruff==0.17.4
python -m pycodestyle --max-line-length=79 src scripts tests
python -m ruff check src scripts tests
```

Эти инструменты не нужны для обучения и не входят в зависимости выполнения.

Тесты: `python -m pytest -q`. Проверяются исключение целевой переменной,
обучение статистик только на обучающей части, независимый расчет признаков строк,
новые категории, полностью пустой числовой столбец, недопустимые расходы,
разделение групп и отложенной выборки, независимость ее состава от меток,
обнаружение правки сохраненных разбиений, ручной расчет метрик, сквозной запуск
и обнаружение правки сохраненных метрик.
