# Подготовка к вопросам преподавателя

Ответы нужно понимать и уметь объяснить своими словами.

1. **Что является X/y?** Объектом служит один пассажир, X содержит доступные поля
   записи, y обозначает `Transported`. Применимость к реальному процессу
   не доказана: это синтетическая учебная задача.
2. **Почему accuracy?** Это метрика соревнования, а классы рабочей выборки почти
   сбалансированы. F1, recall, AUC, log loss и оценка Брайера уточняют разные
   свойства прогнозов.
3. **Почему разделение по группам?** Измеряем качество на новых группах
   путешественников. Случайное разбиение пассажиров отвечает на другой вопрос.
   Здесь его результат близок к групповому; это не доказывает отсутствие связей.
4. **Почему нужна окончательная отложенная выборка?** Решения по перекрестной
   проверке тоже адаптируются к данным. Отложенная выборка не участвует
   в этом цикле и сохраняется для финального сравнения.
5. **Где предотвращается утечка?** `PassengerFeatures` запрещает целевую переменную
   на входе; идентификатор и имя исключены. Группы обучения и проверки
   не пересекаются. Заполнение пропусков, масштабирование и кодирование категорий
   обучаются только на обучающей части фолда. Данные и разбиения проверяются
   по контрольным суммам.
6. **Что означает среднее ± SD?** Среднее и выборочное стандартное отклонение
   пяти значений accuracy. Это не доверительный интервал. Accuracy
   по объединенным OOF-прогнозам учитывает разный размер фолдов.
7. **Что учитывает бутстрэп?** Целые группы выбираются с возвращением, одинаково
   для обеих моделей. Интервалы рассчитаны по готовым OOF-прогнозам;
   полная вариативность повторного обучения и зависимость между
   пересекающимися обучающими частями не учтены.
8. **Что не сработало?** `log1p` расходов ухудшил фиксированный вариант регрессии.
   Результат сохранен. Причина не установлена; возможное объяснение состоит
   в изменении границ решений линейной модели после замены координат.
9. **Помогают ли индикаторы пропусков?** Есть небольшая положительная точечная
   разность, но интервал включает ноль. Убедительного устойчивого выигрыша нет.
10. **Какой следующий шаг?** Проверить нелинейные взаимодействия градиентным
    бустингом с ограниченным бюджетом на тех же фолдах и выполнить абляции.
11. **Какие выводы подтверждены?** У B1 есть преимущество над моделью частот
    классов; у признаков каюты положительная наблюдаемая разность.
    Выигрыш индикаторов пропусков неубедителен; `log1p` ухудшил конкретный вариант.
    Преимущество бустинга еще не проверялось.
