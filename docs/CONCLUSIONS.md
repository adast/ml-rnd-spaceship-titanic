Логистическая регрессия с признаками каюты получила среднюю accuracy **78,803%**
на пяти групповых фолдах рабочей выборки против **50,244%** у B0 и превзошла ее
на всех пяти фолдах. Доступные признаки пассажира содержат полезную для прогноза
информацию в выбранном сценарии новых групп путешественников.
В парных сравнениях по объединенным OOF-прогнозам палуба и борт каюты дали
наблюдаемую прибавку **0,775 п.п.** С индикаторами пропусков разность составила
**0,100 п.п.**, но интервал включает ноль; устойчивый выигрыш не подтвержден.
`log1p` расходов ухудшил accuracy соответствующего варианта на **0,962 п.п.**
Дополнительное преобразование не гарантирует улучшения базовой модели.

Основные слабости B1: ошибки в обе стороны, включая уверенные FP/FN, и
неравномерное качество по срезам. Различия между планетами и группами
являются описательными и не устанавливают причины ошибок.
Следующий эксперимент для HW2 предполагает градиентный бустинг с ограниченным
бюджетом для проверки нелинейных взаимодействий криосна, планеты, каюты и расходов.
Его нужно сравнить на тех же фолдах рабочей выборки и проверить абляциями
добавленных признаков при неизменной B1.
Выводы относятся к одному синтетическому набору данных. Стандартное отклонение
по фолдам не дает доверительного интервала. Групповой бутстрэп готовых
OOF-прогнозов не учитывает полную вариативность повторного обучения.
Выборку из **1725 отложенных строк** следует оценить один раз после фиксации
всех решений, без подбора по ней.
