HW1: воспроизводимая базовая модель Spaceship Titanic

Решение формализует бинарную классификацию Transported и проверяет фиксированную
гипотезу на пассажирах из новых групп путешественников. Предобработка обучается
внутри обучающей части каждого фолда. Сравниваются модель частот классов,
фиксированная логистическая регрессия и три варианта признаков: пять групповых
фолдов при трех начальных числах генератора и отдельная диагностика случайного
разбиения пассажиров.

В отчете сохранены метрики фолдов, OOF-прогнозы, условные интервалы группового
бутстрэпа, разведочный анализ, срезы, частоты FP/FN, два примера с медианной
для своего типа уверенностью и три крайних случая с точными вычислениями моделей.
Окончательная отложенная выборка целыми группами сохранена для финала курса.

Проверки: девять тестов целостности, повторный запуск с закрепленными версиями,
точное совпадение вероятностей и независимый пересчет метрик фолдов.
README содержит выводы, ограничения и следующую проверяемую гипотезу.
